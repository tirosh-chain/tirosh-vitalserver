# Release Notes

이 문서는 Vital Server Helper 배포 버전별 변경 사항을 기록합니다.

## 작성 형식

```text
## <version>

Release date:
Target:

### Added

### Changed

### Fixed

### Known Limits

### Upgrade Notes
```

## 초안

아직 공개 release version이 확정되지 않았습니다.

초기 release note에는 아래 항목을 포함합니다.

- Vital Server Helper 공개 목적
- 병원 내 기본 모드 지원 범위
- cloud 선택 모드 지원 조건
- Health Check 초기 범위
- Mac hardware appliance 전제
- 알려진 제한 사항
