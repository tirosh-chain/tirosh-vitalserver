# Generated Contract Artifacts

`control.v1.bundle.json` is a deterministic, self-contained OpenAPI 3.1 bundle generated from `../openapi/control.v1.json` and the canonical JSON Schema documents.

Do not edit it manually. Regenerate it with:

```sh
make -C runtime-platform contract-generate
```

The bundle is checked in so future Go and TypeScript client generation uses the same resolved source without reaching outside this repository root.
