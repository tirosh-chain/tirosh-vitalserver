# Guest Bundled Upstream Image-set Effect Executor

This release-owned C66 executable is a C55 layer effect for the
`bundled-upstream` C26 layer. It checks the exact staged archive bytes, sends
the archive plus a C64 compare-and-swap command through the declared
Host-loopback C32 bridge, and writes one C55 receipt.

It does not read C64 state, infer a Guest address, start Docker, run Compose,
or repair container state. C64 alone owns those Guest effects and its durable
operation record.
